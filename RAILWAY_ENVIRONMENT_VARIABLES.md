# Railway Environment Variables - Complete Reference

This document provides a comprehensive list of all environment variables needed for deploying PharmaGo to Railway.

## 📦 Quick Reference

### Backend Service Variables
- **Required**: 15 variables
- **Auto-generated by Railway**: 2 variables (DATABASE_URL, REDIS_URL)
- **Optional**: 8 variables

### Frontend Service Variables
- **Required**: 3 variables
- **Optional**: 4 variables

## 🔧 Backend Service Environment Variables

### Django Core (Required)

| Variable | Example Value | Description | How to Generate |
|----------|---------------|-------------|-----------------|
| `SECRET_KEY` | `django-insecure-xy...` | Django secret key for cryptographic signing | Run: `python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"` |
| `DEBUG` | `False` | Enable/disable debug mode | Set to `False` for production |
| `ALLOWED_HOSTS` | `backend.railway.app` | Comma-separated list of allowed hosts | Get from Railway after generating domain |

### Database Configuration (Auto-Generated)

| Variable | Auto-Generated? | Description |
|----------|-----------------|-------------|
| `DATABASE_URL` | ✅ Yes (PostgreSQL Plugin) | Full database connection URL |

**Alternative Manual Configuration:**
```
DB_NAME=railway
DB_USER=postgres
DB_PASSWORD=<from-railway>
DB_HOST=<from-railway>
DB_PORT=5432
```

### Redis Configuration (Auto-Generated)

| Variable | Auto-Generated? | Description |
|----------|-----------------|-------------|
| `REDIS_URL` | ✅ Yes (Redis Plugin) | Full Redis connection URL |

### File Storage - AWS S3 (Required)

| Variable | Example Value | Description | How to Get |
|----------|---------------|-------------|------------|
| `AWS_ACCESS_KEY_ID` | `AKIAIOSFODNN7...` | AWS access key | AWS IAM Console |
| `AWS_SECRET_ACCESS_KEY` | `wJalrXUtnFEMI...` | AWS secret key | AWS IAM Console |
| `AWS_STORAGE_BUCKET_NAME` | `pharmago-uploads` | S3 bucket name | Create in AWS S3 |
| `AWS_S3_REGION_NAME` | `ap-southeast-2` | AWS region | Choose nearest region |

**Setting up AWS S3:**
1. Go to [AWS S3 Console](https://s3.console.aws.amazon.com/)
2. Create new bucket: `pharmago-uploads`
3. Go to [IAM Console](https://console.aws.amazon.com/iam/)
4. Create new IAM user with S3 permissions
5. Generate access keys
6. Copy keys to Railway variables

### Google Maps API (Required)

| Variable | Example Value | Description | How to Get |
|----------|---------------|-------------|------------|
| `GOOGLE_MAPS_API_KEY` | `AIzaSyD-9tSrke...` | Google Maps API key | Google Cloud Console |

**Setting up Google Maps API:**
1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create new project or select existing
3. Enable APIs: Maps JavaScript API, Distance Matrix API, Geocoding API
4. Go to Credentials → Create Credentials → API Key
5. Restrict key to your domains
6. Copy key to Railway

## 📱 Mobile App Configuration (Not deployed on Railway)

The mobile app is deployed via Expo EAS, but needs to know the Railway backend URL.

Update `mobileapp/apps/customer-app/services/api.ts`:

```typescript
const getApiBaseUrl = () => {
  // Production - Railway backend
  if (process.env.EXPO_PUBLIC_ENV === 'production') {
    return 'https://your-backend.railway.app/api/v1';
  }
  
  // Staging - Railway backend
  if (process.env.EXPO_PUBLIC_ENV === 'staging') {
    return 'https://your-backend-staging.railway.app/api/v1';
  }
  
  // Development - local or LAN
  // ... existing development logic
};
```

Then in `app.config.js` or `.env`:
```
EXPO_PUBLIC_ENV=production
EXPO_PUBLIC_API_BASE=https://your-backend.railway.app
```

## 🔐 Security Best Practices

### Secret Key Generation

Generate a strong Django secret key:

```bash
# Method 1: Using Django
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

# Method 2: Using OpenSSL
openssl rand -base64 50

# Method 3: Using Python
python -c "import secrets; print(secrets.token_urlsafe(50))"
```

### Environment Variable Security

✅ **DO:**
- Use Railway's built-in variable encryption
- Rotate secrets regularly
- Use different keys for staging/production
- Enable Railway's secret redaction in logs

❌ **DON'T:**
- Commit `.env` files to git
- Share secrets via Slack/email
- Use same secrets across environments
- Use weak or default passwords

### AWS IAM Best Practices

Create dedicated IAM user with minimal permissions:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::pharmago-uploads",
        "arn:aws:s3:::pharmago-uploads/*"
      ]
    }
  ]
}
```

## 📊 Variable Import/Export

### Export from Local .env

If you have a local `.env` file, you can batch-import to Railway:

1. Install Railway CLI:
```bash
npm install -g @railway/cli
```

2. Login:
```bash
railway login
```

3. Link project:
```bash
railway link
```

4. Set variables:
```bash
# Set from .env file
railway variables --set-from-env-file .env

# Or set individually
railway variables set SECRET_KEY="your-secret-key"
railway variables set DEBUG="False"
```

### Batch Import Template

Create a file `railway-vars.txt`:
```
SECRET_KEY=your-secret-key-here
DEBUG=False
ALLOWED_HOSTS=backend.railway.app
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=wJal...
AWS_STORAGE_BUCKET_NAME=pharmago-uploads
AWS_S3_REGION_NAME=ap-southeast-2
GOOGLE_MAPS_API_KEY=AIza...
FRONTEND_URL=https://frontend.railway.app
ENABLE_API_USAGE_MW=1
ENABLE_SYSTEM_HEALTH_MW=1
DISABLE_THROTTLE=0
LIGHT_LOGGING=0
DISABLE_FILE_LOG=1
EMAIL_CONSOLE=0
```

Then import:
```bash
cat railway-vars.txt | while read line; do
  railway variables set "$line"
done
```

## 🆘 Troubleshooting

### Variable Not Loading

1. Check spelling (case-sensitive)
2. Redeploy after adding variables
3. Check Railway service logs
4. Verify no typos in variable names

### Database Connection Issues

1. Ensure PostgreSQL plugin is active
2. Check `DATABASE_URL` is set
3. Verify `settings.py` uses `dj_database_url`

### Redis Connection Issues

1. Ensure Redis plugin is active
2. Check `REDIS_URL` is set
3. Verify channel layers configuration
