HOW TO GET CLOUDINARY CREDENTIALS
=============================================================================

1. Sign up at: https://cloudinary.com/users/register/free
   - Free tier includes: 25GB storage, 25GB bandwidth/month
   
2. After login, go to Dashboard: https://cloudinary.com/console
   
3. You'll see your credentials:
   - Cloud Name: (visible on dashboard)
   - API Key: (visible on dashboard)
   - API Secret: (click "Show" to reveal)

4. Copy these three values to Railway environment variables

5. OPTIONAL - Create Upload Preset (for direct frontend uploads):
   - Go to Settings → Upload
   - Scroll to "Upload presets"
   - Click "Add upload preset"
   - Set as "Unsigned"
   - Give it a name (e.g., "pharmago-uploads")
   - Save

=============================================================================
SETUP STEPS
=============================================================================

BACKEND:
1. Add PostgreSQL plugin (creates DATABASE_URL automatically)
2. Add Redis plugin (creates REDIS_URL automatically)
3. Generate SECRET_KEY using the command above
4. Sign up for Cloudinary (free)
5. Get Cloudinary credentials from dashboard
6. Set all Cloudinary variables
7. Get backend domain from Railway (after generating domain)
8. Update ALLOWED_HOSTS with your backend domain
9. Set Google Maps API key
10. Deploy

FRONTEND:
1. Deploy backend first
2. Get backend Railway domain
3. Set REACT_APP_API_URL with backend domain + /api/v1
4. Set REACT_APP_BACKEND_URL with backend domain
5. Deploy

POST-DEPLOYMENT:
1. Migrations run automatically (via Procfile)
2. Create superuser: railway run python manage.py createsuperuser
3. Test at: https://your-backend-domain/admin
4. Upload a test file to verify Cloudinary works
5. Check files appear in Cloudinary dashboard
