## 🔧 Configuration Details

### Backend: Procfile

```procfile

release: python manage.py migrate --noinput && python manage.py collectstatic --noinput
```

**Explanation:**
- `web`: Starts Daphne ASGI server (supports WebSocket)
- `release`: Runs migrations and collects static files before deployment

## 🐛 Common Issues & Solutions

### Issue: Build Fails

**Symptoms**: Railway build logs show errors

**Solutions:**
1. Check Python version in `runtime.txt` matches your local
2. Verify all dependencies in `requirements.txt`
3. Check for missing system packages in `nixpacks.toml`
4. Review build logs in Railway dashboard

### Issue: Migrations Fail

**Symptoms**: Release command fails with database errors

**Solutions:**
1. Check `DATABASE_URL` is set (PostgreSQL plugin added)
2. Verify database credentials
3. Run migrations manually: `railway run python manage.py migrate`
4. Check for migration conflicts

### Issue: Static Files Not Loading

**Symptoms**: Admin panel has no CSS

**Solutions:**
1. Verify `collectstatic` runs in Procfile release command
2. Check WhiteNoise is installed and configured
3. Verify `STATIC_ROOT` and `STATIC_URL` settings
4. Check Railway logs for collectstatic errors

### Issue: WebSocket Not Connecting

**Symptoms**: Real-time features don't work

**Solutions:**
1. Verify Daphne is running (not Gunicorn)
2. Check Redis connection (`REDIS_URL` set)
3. Verify `CHANNEL_LAYERS` uses Redis backend
4. Check browser console for WebSocket errors
5. Ensure using `wss://` (not `ws://`) for HTTPS

### Issue: CORS Errors

**Symptoms**: Frontend can't call backend API

**Solutions:**
1. Add frontend URL to `CORS_ALLOWED_ORIGINS`
2. Update `FRONTEND_URL` environment variable
3. Check `ALLOWED_HOSTS` includes backend domain
4. Verify environment variables are set correctly

### Issue: File Upload Fails

**Symptoms**: Can't upload images/documents

**Solutions:**
1. Verify AWS credentials are set
2. Check S3 bucket permissions
3. Test S3 access from Railway shell
4. Check file size limits in settings
5. Review bucket CORS configuration
