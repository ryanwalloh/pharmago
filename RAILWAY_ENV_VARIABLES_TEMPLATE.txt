=============================================================================
SETUP STEPS
=============================================================================

BACKEND:
1. Add PostgreSQL plugin (creates DATABASE_URL automatically)
2. Add Redis plugin (creates REDIS_URL automatically)
3. Generate SECRET_KEY using the command above
4. Get backend domain from Railway (after generating domain)
5. Update ALLOWED_HOSTS with your backend domain
6. Set AWS S3 credentials
7. Set Google Maps API key
8. Deploy

FRONTEND:
1. Deploy backend first
2. Get backend Railway domain
3. Set REACT_APP_API_URL with backend domain + /api/v1
4. Set REACT_APP_BACKEND_URL with backend domain
5. Deploy

POST-DEPLOYMENT:
1. Migrations run automatically (via Procfile)
2. Create superuser: railway run python manage.py createsuperuser
3. Test at: https://your-backend-domain/admin
4. Import data if needed
